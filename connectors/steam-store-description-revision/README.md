# Steam store description revision

Prepares a deterministic, local, text-only Steam store description revision for human review. It covers localized short descriptions and `About This Game` copy only.

It requires an English fallback, accepts the current full-platform Steam language codes, blocks formatting and obvious links, binds launch-feature/translation/rights evidence refs, and preserves semantic review as pending. It does not access Steamworks, upload or publish copy, submit review, approve a launch claim, or cover graphical assets, system requirements, tags, ratings, Early Access or mature-content declarations.
