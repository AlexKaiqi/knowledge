# Distribution Impact Observation Evaluation Maintainer

Proposal-only Collector。它观察 Steam UTM、App Store campaign/Analytics Reports 与 Google Play store-listing 的原生指标、成熟期、阈值、未归因和 coverage 语义，并检查本地 proof freshness。

变化只生成 review 或 reprobe proposal；不会登录开发者账号、读取报告、改变 definition、重写 Connector 或自动准入平台读取能力。
