# Contract eval

The local fixture covers:

- support and counterevidence refs resolve only to supplied evidence;
- a material conflict remains explicit;
- unrelated evidence remains unassigned;
- frequency is derived from the bounded sample and marked sample-only;
- output requires human review and cannot authorize execution;
- hidden route and identity fields are rejected.

This is an L0/L1 contract eval with a scripted Agent response. Real-Agent semantic quality, recall, stability and multilingual behavior require separate L3 evaluation and are not claimed by this file.
