# 产品范围与价值门

## 目标

本仓库不是公共 API 或包管理器百科。它维护能让 Agent 更可靠地完成下面闭环的知识和能力：

```text
发现真实需求
→ 研究市场、竞品、内容渠道、模型与评测
→ 制作并发布内容或 App
→ 获得分发与影响力
→ 收集评论、问题、指标和用户反馈
→ 形成下一轮产品决策
```

## 准入问题

新增 Subject、Capability 或 Collector 前必须依次回答：

1. 它推进闭环中的哪一个具体结果？
2. 没有它，哪个产品决策或执行动作无法可靠完成？
3. 模型或已有工具是否已经能直接完成？若能，为什么仍需在 OKF 积累？
4. 输出是否是决策级事实，而不是容易重新查询的通用技术元数据？
5. 是否能通过 live/sandbox probe 验证，并由 Collector 持续维护？

第 1 或第 2 问没有具体答案，不进入仓库。第 3 问没有额外复杂度、安全或稳定性收益时，只使用现有工具；最多保留隐藏 Collector，不建立公共 Subject/Capability。

## 优先域

- 自媒体平台：发布、搜索、账号内容、评论、指标、规则与回执。
- 应用商店：搜索、榜单、详情、版本发布、审核状态、公开评论与自有应用反馈。
- 需求来源：GitHub Issues、应用商店评论、公开社区和用户反馈。
- 研究来源：竞品变化、模型、数据集、评测集和高信号行业来源。
- 影响力：跨渠道发布结果、曝光互动、评论主题、转化与复盘。

## 非目标

- 仅因为 API 公开或容易 live probe 就接入的平台。
- 通用包、镜像、制品、依赖或漏洞元数据百科。
- 模型已经知道且现有工具可直接调用的普通开发操作。
- 无法影响产品、发布、传播、需求或研究决策的技术完整性证明。
