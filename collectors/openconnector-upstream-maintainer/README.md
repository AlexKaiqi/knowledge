# OpenConnector upstream Maintainer

This proposal-only Collector watches the audited OpenConnector runtime, its verification/security/action contracts, OOMOL managed-route price and Skill semantics, release tags, repository heads, and the unrelated same-name placeholder repository.

It never installs OpenConnector, creates accounts, accepts terms, configures a connection, runs a paid action or changes the candidate route automatically. A drift result is evidence for review, not permission to switch routes or admit knowledge.
