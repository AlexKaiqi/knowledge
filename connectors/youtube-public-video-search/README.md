# YouTube public video search Connector candidate

Hidden candidate over the official YouTube Data API `search.list` method. It performs one bounded video-only keyword search and emits a metadata-only, channel-identity-free page.

It remains non-routable until an owned Google Cloud project/API key is bound and a live probe passes. API key creation, terms acceptance, quota extension, OAuth, uploads, comments, analytics, pagination, transcripts, and media downloads are out of scope.
