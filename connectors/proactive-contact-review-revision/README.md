# Proactive contact review revision

Hidden deterministic Connector for `/capabilities/assistant/prepare-proactive-contact-review-revision.md`.

It evaluates one owner-scoped contact candidate against explicit opt-in, pause, IANA-time-zone quiet windows, recent activity, minimum gap, daily/unanswered caps, source visibility, availability and deduplication. Passing only prepares an immutable human-review revision; it never creates a message, selects a credential, attempts delivery or authorizes notification.
