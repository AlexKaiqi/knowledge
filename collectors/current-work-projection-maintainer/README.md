# Current work projection maintainer Collector

This hidden, proposal-only Collector watches the fixed and moving production maintainer, local-write service semantics, repository layout, production E2E evidence and local verification freshness.

Implementation drift requests Connector review; E2E or pinned-evidence drift requests knowledge review. It never changes the production plugin, runs a model, writes current work, advances a Session cursor, creates a durable proposal or reruns the local-write probe automatically.
