# Steam system requirements revision Connector

This hidden deterministic Connector freezes owned Windows, macOS and Linux/SteamOS requirement text together with build, depot, public-package and launch-test evidence references. It prepares a review revision only.

It does not inspect or upload a build, log in to Steamworks, change supported operating-system checkboxes, edit depots or packages, preview or save a store page, move a build to the default branch, mark anything ready for review, publish or release.
